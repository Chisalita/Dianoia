# nand2tetris

Work from *The Elements of Computing Systems*, kept separate from Dianoia
proper so the two designs never quietly merge.

    projects/01  boolean logic
    projects/02  boolean arithmetic
    projects/03  sequential logic
    projects/04  machine language
    projects/05  the Hack computer
    projects/06  assembler
    ...

The course's own simulators are the reference for these — its test scripts and
`.cmp` files only run there. Digital is for Dianoia.

Nothing here is authoritative for the Dianoia ISA. When a good idea appears in
the course, it gets copied across deliberately and written down in `docs/`, not
imported by accident.
